# telefeed-public

Публичная «карточка» приложения TeleFeed для подключения TON-кошелька (TON Connect).

- `tonconnect-manifest.json` — название, адрес и значок приложения: кошелёк читает этот файл, когда вы подключаете его к TeleFeed.
- `icon.png` — значок 180×180.

Здесь нет кода, ключей и личных данных — только то, что кошелёк показывает при подключении.

Сайт: https://adalat777.github.io/telefeed-public/
